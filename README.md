# dame_assistant
DAME, short for DataMesh, is an independent AI assistant. DAME comes pre-configured without any training, and we designed it to be open-source, leaving the training process up to you. It currently comes with a pre-built wiki, a “learning threshold,” NLP capabilities, a neural network, and a static language model.

NOTE:I made it up turkish only but next time i'll be publish it with other language preferences with more modern and stable.
