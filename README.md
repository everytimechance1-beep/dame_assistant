# dame_assistant
DAME, short for DataMesh, is an independent AI assistant. DAME comes pre-configured without any training, and we designed it to be open-source, leaving the training process up to you. It currently comes with a pre-built wiki, a “learning threshold,” NLP capabilities, a neural network, and a static language model.
I haven’t been able to fully develop this NLP engine because my financial situation and studies don’t really allow me to focus on software; if you’d like to develop it further, or if you’ve already done so, I’d love to see the improved version
Also, I’m open to your ideas and suggestions to help improve my projects – just get in touch and let me know:D
